# การสะกดคำ คำยืมภาษาอังกฤษ และหลักการเว้นวรรค (Orthography, Loanwords, and Spacing)

ไฟล์นี้รวบรวมหลักการสะกดคำภาษาไทยที่ถูกต้อง ทั้งคำไทยแท้ที่มักสะกดผิด และคำทับศัพท์ตามพจนานุกรมฉบับราชบัณฑิตยสภา รวมถึงหลักการเว้นวรรคภาษาไทยให้อ่านง่าย สบายตา และถูกต้องตามแบบแผน

---

## 1. คำไทยแท้ที่มักสะกดผิดบ่อย (Common Thai Misspellings)

| คำที่สะกดถูกต้อง | คำที่มักสะกดผิด | เกร็ดการจำ |
|---|---|---|
| **สังเกต** | สังเกตุ | ไม่มี สระอุ (จำว่า "สังเกตการณ์") |
| **อนุญาต** | อนุญาติ | ไม่มี สระอิ (จำว่า "ใบอนุญาต" ไม่มี ญาติ) |
| **นะคะ** | นะค่ะ | "นะค่ะ" ไม่มีในภาษาไทย / "ค่ะ" ใช้ตอบรับและบอกเล่า |
| **ลายเซ็น** | ลายเซ็นต์ | ใช้ ไม้ทัณฑฆาต (การันต์) บน น |
| **รสชาติ** | รสชาด | ใช้ "ชาติ" เหมือนเชื้อชาติ |
| **กะทันหัน** | กระทันหัน | ไม่มี ร ควบกล้ำ |
| **โอกาส** | โอกาศ | ใช้ ส เสือ สะกด |
| **กฎหมาย / กฎเกณฑ์** | กฏหมาย / กฏเกณฑ์ | ใช้ ฎ ชฎา (หางสั้น 1 หยัก) |
| **ปรากฏ** | ปรากฎ | ใช้ ฏ ปฏัก (หางยาว 2 หยัก) |
| **สัมมนา** | สัมนา | ใช้ ม ม้า 2 ตัว |
| **ผัดวันประกันพรุ่ง** | ผลัดวันประกันพรุ่ง | "ผัด" = เลื่อนเวลา / "ผลัด" = สับเปลี่ยน (เช่น ผลัดเวร) |
| **เบื้องต้น** | เบื่องต้น | ใช้ ไม้โท |
| **พิถีพิถัน** | ประณีตประนอม / พิถีพิถัน | สะกดด้วย ถ ถุง |

## 2. เมื่อไหร่ควรใช้ภาษาอังกฤษ vs แปลไทย vs ทับศัพท์

ภาษาไทยในวงการทำงานและไอที มีการหยิบยืมคำภาษาอังกฤษมาใช้เยอะมาก เพราะคำภาษาอังกฤษหลายคำสื่อความหมายได้ตรงจุดและเป็นสากลมากกว่า

### ใช้คำภาษาอังกฤษตรง ๆ
ใช้กับคำศัพท์เทคนิคเฉพาะทาง คำสั่ง โค้ด หรือเครื่องมือที่คนทำงานคุ้นเคยในรูปภาษาอังกฤษมากกว่า หากพยายามแปลเป็นไทยจะทำให้เข้าใจยากหรือดูฝืนธรรมชาติ

- ตัวอย่าง : config, bug, deploy, API, commit, push, pull, PR, branch, staging, production, refactor, backend, frontend, token, cache, endpoint, syntax, framework, terminal, repository

### ใช้คำทับศัพท์ภาษาไทยที่ถูกต้อง
ใช้กับคำที่คนไทยคุ้นเคยกับการออกเสียงและเขียนเป็นภาษาไทย และมีรูปคำทับศัพท์ที่ชัดเจนตามราชบัณฑิตยสภา

- ตัวอย่าง : เซิร์ฟเวอร์, อัปเดต, โปรเจกต์, เวอร์ชัน, เว็บไซต์, อีเมล, อินเทอร์เน็ต, ดิจิทัล, แอปพลิเคชัน (หรือ แอป), ลิงก์, ฟังก์ชัน, โค้ด, แพ็กเกจ

### ใช้คำแปลภาษาไทย
ใช้เมื่อคำแปลภาษาไทยนั้นแพร่หลาย ชัดเจน และคนทั่วไปเข้าใจได้ทันที

- ตัวอย่าง : ฐานข้อมูล (Database), ปัญญาประดิษฐ์ (AI ในบริบททางการ), รหัสผ่าน (Password), ค้นหา (Search)

### การอธิบายความหมายภาษาอังกฤษสำหรับคนทั่วไป
หากจำเป็นต้องใช้คำภาษาอังกฤษกับคนนอกสายงานหรือผู้ใช้งานทั่วไป ให้ใส่คำอธิบายสั้น ๆ หรือเปรียบเทียบควบคู่ไปด้วยเสมอ :

- config หมายถึง การตั้งค่าระบบหรือโปรแกรม
- bug หมายถึง จุดผิดพลาดที่ทำให้โปรแกรมทำงานไม่ถูกต้อง
- deploy หมายถึง การนำโปรแกรมขึ้นใช้งานจริงบนระบบ
- API หมายถึง ช่องทางเชื่อมต่อเพื่อส่งรับข้อมูลระหว่างระบบ

## 4. หลักการเว้นวรรคภาษาไทยให้อ่านง่ายและถูกต้อง

### เว้นวรรคระหว่างภาษาไทยกับภาษาอังกฤษ
ให้เว้นวรรค 1 เคาะ เพื่อแยกสายตาให้อ่านง่าย
- ถูกต้อง : "เปิด terminal แล้วรันคำสั่ง"

### เว้นวรรคระหว่างภาษาไทยกับตัวเลข
ให้เว้นวรรค 1 เคาะ เสมอ
- ถูกต้อง : "มีบั๊ก 3 จุดที่ต้องแก้"

### เว้นวรรคไม้ยมก (ๆ)
ตามหลักเกณฑ์มาตรฐาน ให้เว้นวรรคทั้งหน้าและหลังไม้ยมก
- ถูกต้อง : "แก้ปัญหาจริง ๆ", "เขียนสั้น ๆ", "อธิบายง่าย ๆ"

### เว้นวรรคเครื่องหมายวงเล็บ ( )
เว้นวรรค 1 เคาะ หน้าวงเล็บเปิด และหลังวงเล็บปิด ส่วนข้อความข้างในให้เขียนชิดวงเล็บ
- ถูกต้อง : "ตรวจสอบการตั้งค่า (config) ให้เรียบร้อย"

### เว้นวรรคเครื่องหมายทวิภาค (:)
ให้เว้นวรรค 1 เคาะ หลังเครื่องหมายทวิภาค
- ถูกต้อง : "วิธีแก้ : ทำตามขั้นตอนต่อไปนี้"

### เว้นวรรคระหว่างประโยคหรือวรรคตอน
เมื่อจบประโยคย่อยหรือต้องการแยกความคิด ให้เว้นวรรค 1 ถึง 2 เคาะ เพื่อให้ผู้อ่านพักสายตาและจับใจความได้ทันที อย่าเขียนข้อความยาวติดกันเป็นพรืดโดยไม่เว้นวรรค
