# บัญชีคำศัพท์และข้อกำหนดตามระดับภาษา (Word Guidelines & Register Matrix)

> **เป้าหมายหลัก:** ป้องกันไม่ให้ภาษาไทยมีสำนวนแปล AI หรือคำฟุ่มเฟือยของระบบราชการ โดยยังคง **"ความเป็นธรรมชาติเหมือนมนุษย์คุยกับมนุษย์ตามระดับกาลเทศะจริง"**

---

## 1. คำแปลสำนวนภาษาอังกฤษที่ต้องหลีกเลี่ยง (Translationese Patterns)

จงใช้คำกริยาและสำนวนภาษาไทยแท้แทนโครงสร้างแปลตรงตัวจากภาษาอังกฤษ:

| สำนวนแปลอังกฤษ (ควรเลี่ยง) | คำภาษาไทยธรรมชาติที่ควรใช้ | บริบทตัวอย่าง |
|---|---|---|
| **สร้างความมั่นใจว่า (Make sure that)** | ดูให้แน่ใจว่า, ตรวจดูให้เรียบร้อย, ให้มั่นใจว่า | *"ตรวจดูให้เรียบร้อยว่าบันทึกไฟล์แล้ว"* |
| **มันสมเหตุสมผล (It makes sense)** | ฟังดูเข้าท่า, สมเหตุสมผลดี, เหมาะสมแล้ว | *"แนวทางนี้ฟังดูเข้าท่าและทำได้จริง"* |
| **ในตอนท้ายของวัน (At the end of the day)** | ท้ายที่สุดแล้ว, สรุปแล้ว, ในท้ายที่สุด | *"ท้ายที่สุดแล้ว ผลงานคือสิ่งสำคัญที่สุด"* |
| **นำมันไปสู่อีกระดับ (Take it to the next level)** | ยกระดับ, พัฒนาขึ้นไปอีกขั้น | *"ยกระดับระบบให้รองรับผู้ใช้ได้มากขึ้น"* |
| **คุณสามารถ... (You can...)** | สามารถ..., [ทำกริยานั้นได้เลย] | *"ดาวน์โหลดรายงานได้ทันที"* |
| **มีความสามารถในการ (Have the ability to)** | สามารถ, ทำได้ | *"ระบบนี้รองรับผู้ใช้ได้ 1,000 คนพร้อมกัน"* |

## 2. กฎการใช้คำตามระดับภาษา (Register-Aware Matrix)

| คำศัพท์ | บริบทสนทนาทั่วไป / UX Copy / แชททีม | บริบทวิชาการ / นิติกรรมสัญญา / หนังสือทางการ |
|---|---|---|
| **อย่างไรก็ตาม** | [ไม่แนะนำ] เลี่ยง (ใช้ "แต่", "ทว่า") | **อนุญาตและจำเป็น** (แสดงข้อจำกัดตรรกะ) |
| **นอกจากนี้ / ยิ่งไปกว่านั้น** | [ไม่แนะนำ] เลี่ยง (ใช้ "แล้วก็", "แถมยัง") | **อนุญาตและจำเป็น** (เสริมหลักฐานทางวิชาการ) |
| **ดังนั้น / จึงส่งผลให้** | [ไม่แนะนำ] เลี่ยง (ใช้ "ก็เลย", "ทำให้") | **อนุญาตและจำเป็น** (สรุปผลเชิงตรรกะ) |
| **ทั้งนี้** | [ไม่แนะนำ] เลี่ยง (ใช้ "โดย", "ส่วน") | **อนุญาตและจำเป็น** (กำหนดเงื่อนไขทางสัญญา) |
| **ดำเนินการ / ปฏิบัติการ** | [ไม่แนะนำ] เลี่ยง (ใช้กริยาตรง เช่น จัดการ, ทำ) | **อนุญาต** (เช่น ดำเนินการตามขั้นตอนกฎหมาย) |
| **ดังกล่าว** | [ไม่แนะนำ] เลี่ยง (ใช้ "นี้/นั้น", "รายการนี้") | **อนุญาต** (ระบุเอกสาร/ข้อความผูกพันสัญญา) |

---

## 3. บัญชีคำสะกดถูกต้องตามพจนานุกรม (Strict Orthography Whitelist)

จงใช้เฉพาะรูปแบบคำที่สะกดถูกต้องต่อไปนี้เสมอ:

### 3.1 คำภาษาไทย
`สังเกต`, `อนุญาต`, `นะคะ`, `ลายเซ็น`, `รสชาติ`, `กะทันหัน`, `โอกาส`, `กฎหมาย`, `ปรากฏ`, `สัมมนา`, `ผูกพัน`, `พิถีพิถัน`, `มุกตลก`, `โลกาภิวัตน์`, `คลินิก`

### 3.2 คำทับศัพท์ภาษาอังกฤษที่พบบ่อย
`เช็ก`, `อัปเดต`, `อัปโหลด`, `เวอร์ชัน`, `โปรเจกต์`, `เซิร์ฟเวอร์`, `คลิก`, `บล็อก`, `ดิจิทัล`, `อีเมล`, `แอป`, `ลิงก์`, `ฟังก์ชัน`, `สคริปต์`, `คอมเมนต์`, `โพสต์`, `โค้ด`, `แพ็กเกจ`, `ไดเรกทอรี`, `กราฟิก`, `ล็อกอิน`

---

## 4. บัญชีสแลงที่ตายแล้ว (Dead & Cringe Slang Blacklist) vs สแลงอมตะ (Lexicalized Whitelist)

### [ไม่แนะนำ] สแลงตายแล้ว / เชยมาก ห้าม AI ริเริ่มใช้เด็ดขาด (Dead Slang Blacklist):
- `จุงเบย`, `บ่องตง`, `ฝุดๆ`, `แว้น`, `ชะนี`, `จ๊าบ`, `เมพขิงๆ`, `กรี๊ดสลบ`, `มะนาวต่างดุ๊ด`, `ฟินเฟร่อ`

### สแลงอมตะที่กลายเป็นภาษาพูดถาวร ใช้ได้ในระดับกันเอง (Lexicalized Whitelist):
- `นอยด์`, `ฟิน`, `ปัง`, `บ้ง`, `ช็อตฟีล`, `แซว`, `เฟล`, `โดนเท`, `แกง`, `ตัวตึง`, `ดาเมจ`, `งานเข้า`

---

## 5. การใช้คำศัพท์เฉพาะทางสายวิชาชีพ (Domain Jargon Standard)

- **สายงานออกแบบ (Design):** คงรูปทับศัพท์ภาษาอังกฤษตามสากล: `Wireframe`, `Mockup`, `Prototype`, `User Journey`, `Pain point`, `Drop-off rate`, `Bleed (ระยะตัดตก)`, `Die-cut (ไดคัท)`, `Create Outline`
- **สายงานพัฒนาซอฟต์แวร์ (Dev):** อนุญาตทับศัพท์สากลในโค้ดและแชท: `API`, `Bug`, `Deploy`, `Staging`, `Merge`, `Branch`, `Pipeline`, `Latency`, `Throughput`
