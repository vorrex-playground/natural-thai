# มาตรฐานการสื่อสารข้อมูลการเงิน รายงานนักลงทุน และชื่อนิติบุคคล (Financial & Corporate Standards)

> **เป้าหมายหลัก:** สื่อสารข้อมูลตัวเลข งบการเงิน ชื่อบริษัท และวาทศิลป์ทางการเงินตามมาตรฐานสากลและระเบียบกรมพัฒนาธุรกิจการค้า (DBD) / สำนักงาน ก.ล.ต. / ราชบัณฑิตยสภา

---

## 1. กฎการเว้นวรรคชื่อนิติบุคคลและบริษัท (Corporate Naming & Spacing - DBD & ORST)

ตามหลักเกณฑ์ของสำนักงานราชบัณฑิตยสภา และระเบียบการจดทะเบียนนิติบุคคลของกรมพัฒนาธุรกิจการค้า (DBD):
- **ต้องเว้นวรรค 1 เคาะหน้าคำว่า 'จำกัด' และ '(มหาชน)' เสมอ :**
  - [ถูกต้อง] `ธนาคาร [ชื่อธนาคาร] จำกัด (มหาชน)`
  - [ถูกต้อง] `บริษัท สยามพัฒนาค้าปลีก จำกัด`
  - [ไม่แนะนำ - ติดกันเป็น AI] `*ธนาคารพาณิชย์จำกัด`, `*บริษัทตัวอย่างจำกัด(มหาชน)`
- **ห้างหุ้นส่วนจำกัด :** เว้นวรรค 1 เคาะหลังคำว่า ห้างหุ้นส่วนจำกัด เช่น `ห้างหุ้นส่วนจำกัด ก้าวหน้าพาณิชย์`

---

## 2. วาทศิลป์การสื่อสารของธนาคารและสถาบันการเงิน (Natural Banking Discourse)

ธนาคารในประเทศไทย **ไม่เคยใช้สำนวนแปล AI แบบผลักความต้องการของธนาคารไปสั่งลูกค้า** (เช่น *"เพื่อให้ธนาคาร...รักษามาตรฐานได้ ลูกค้าต้อง..."*):

| [ไม่แนะนำ] สำนวนแปล AI แข็งทื่อ (Corporate-Centric) | [แนะนำ] ภาษาธนาคารไทยที่เป็นธรรมชาติ (Customer-Centric / Transaction Terms) |
|---|---|
| *"เพื่อให้ธนาคาร [ชื่อธนาคาร] จำกัด (มหาชน) สามารถรักษามาตรฐานการให้บริการได้ ลูกค้ามีความจำเป็นที่จะต้องทำการโอนเงิน..."* | **ภาษาบริการ :** *"เพื่อความสะดวกรวดเร็วและต่อเนื่องในการทำรายการ กรุณาดำเนินการโอนเงินข้ามเขตภายใน..."*<br>**ภาษาเงื่อนไขทางการ (T&C) :** *"กำหนดเวลาทำธุรกรรม : การโอนเงินข้ามเขตต้องดำเนินการให้เสร็จสิ้นภายใน..."* |
| *"เพื่อให้ระบบธนาคารมีความปลอดภัย ลูกค้าต้องเปลี่ยนรหัส"* | *"เพื่อความปลอดภัยของบัญชี กรุณาเปลี่ยนรหัสผ่านของท่านทันที"* |

## 3. ทฤษฎีความอ่านง่ายของรายงานการเงิน (Financial Readability - Feng Li 2008; Loughran & McDonald 2014)

รายงานทางการเงินที่ใช้ภาษาชัดเจน กระชับ และตรงไปตรงมา ช่วยลดความไม่สมมาตรของข้อมูล (Information Asymmetry):
1. **ระบุตัวเลขคู่กับปัจจัยขับเคลื่อนเสมอ (Number + Causal Driver) :**
   - [แนะนำ] *"รายได้เติบโต 14.2% YoY จากการขยายฐานลูกค้าบริการคลาวด์เพิ่มขึ้น 3 ราย"*
2. **ความแม่นยำของทศนิยมและหน่วยนับ :** กำกับหน่วยเงิน (บาท, ล้านบาท, %) ให้ชัดเจนทุกครั้ง

## 4. แม่แบบการแจ้งเตือนพอร์ตและระบบอัตโนมัติ (Real Automated Financial Notifications)

### ก. การแยกแยะระบบอัตโนมัติ vs แชทเจ้าหน้าที่ (System Auto-Mail vs Human Agent)
- **อีเมล/SMS จากระบบอัตโนมัติ (System-Generated Alert) :** **งดใส่คำลงท้ายพูด "ครับ/ค่ะ" ในเนื้อหาแจ้งเตือน** ให้ใช้ภาษาทางการที่เป็นกลาง (Impersonal Formal)
- **ศัพท์การเงินที่ถูกต้อง :** ใช้ **"ฝากเงินเข้าบัญชี"** หรือ **"วางหลักประกันเพิ่ม"** (ไม่ใช้คำภาษาปากแบบ "เติมเงิน")

### ข. ตัวอย่างจริงที่โบรกเกอร์ไทยใช้งาน

| ช่องทางการสื่อสาร | ข้อความตัวอย่างที่ถูกต้องตามมาตรฐานสถาบันการเงิน |
|---|---|
| **SMS / Push Notification** | `แจ้งเตือน Call Margin บัญชี xxx: กรุณาฝากเงินหรือวางหลักประกันเพิ่ม 79,100 บาท ภายใน 19 ส.ค. 69 เวลา 15:30 น. เพื่อป้องกันการบังคับขาย (Force Sell) สอบถามโทร 02-xxx-xxxx` |
| **อีเมลแจ้งเตือนอัตโนมัติ (Auto-Mail)** | `เรื่อง : แจ้งเตือนการเรียกวางหลักประกันเพิ่ม (Margin Call)<br><br>เรียน ท่านผู้ถือบัญชีหลักทรัพย์ เลขที่ xxx<br><br>เนื่องจากมูลค่าหลักประกันในบัญชีของท่านลดลงต่ำกว่าเกณฑ์หลักประกันรักษาสภาพ (Maintenance Margin) มียอดที่ต้องนำมาวางเพิ่มจำนวน 79,100.00 บาท<br><br>กรุณาฝากเงินเข้าบัญชีหรือลดสถานะการถือครองหลักทรัพย์ ภายในวันที่ 19 สิงหาคม 2569 ก่อนเวลา 15:30 น. มิฉะนั้น บริษัทฯ มีความจำเป็นต้องดำเนินการบังคับขาย (Force Sell) ตามระเบียบของตลาดหลักทรัพย์แห่งประเทศไทย<br><br>บริษัทหลักทรัพย์ ... จำกัด (มหาชน)<br>(อีเมลฉบับนี้เป็นการแจ้งเตือนจากระบบอัตโนมัติ กรุณาอย่าตอบกลับ)` |

## 4. คำศัพท์ตลาดทุน มาตรฐานบัญชี TFRS และตัวย่อนิติบุคคล

| ศัพท์การเงิน / บัญชี | คำแปลที่ถูกต้อง (Natural Thai) | ห้ามแปลตรงตัว (AI Translation Traps) |
|---|---|---|
| **ECL (Expected Credit Loss)** | **ผลขาดทุนด้านเครดิตที่คาดว่าจะเกิดขึ้น** | *การสูญเสียสินเชื่อที่คาดหวัง* |
| **Provision / Set aside** | **ตั้งสำรอง** (ห้ามใช้ "จัดตั้งสำรอง") | *การจัดตั้งเงินสำรอง* |
| **Default** | **ผิดนัดชำระหนี้** | *ค่าเริ่มต้น / ละเลย* |
| **Underwrite** | **รับประกันการจัดจำหน่าย** | *เขียนข้างใต้* |
| **Leverage** | **การใช้หนี้สิน / พลังทวีทางการเงิน** | *คานงัด* |
| **YoY / QoQ / YTD** | **เทียบช่วงเดียวกันของปีก่อน / เทียบไตรมาสก่อน / ตั้งแต่ต้นปีถึงปัจจุบัน** | - |

### การเว้นวรรคตัวย่อนิติบุคคล
- `บมจ. [ชื่อบริษัท]` (เว้น 1 เคาะหลังจุด)
- `บจก. [ชื่อบริษัท]` (เว้น 1 เคาะหลังจุด)
- `หจก. [ชื่อห้าง]` (เว้น 1 เคาะหลังจุด)

## 5. คำศัพท์กองทุนรวม (บลจ.) ประกันภัย (คปภ.) และตลาดทุน (SET/TFEX)

| หมวดหมู่ | คำศัพท์ภาษาอังกฤษ | คำแปล / การใช้ภาษาไทยทางการที่ถูกต้อง | ข้อห้าม / คำแปลผิด (AI Traps) |
|---|---|---|---|
| **กองทุนรวม (บลจ.)** | **NAV (Net Asset Value)** | **มูลค่าทรัพย์สินสุทธิ** | *มูลค่าสินทรัพย์สุทธิ* |
| | **AUM (Assets Under Management)** | **มูลค่าทรัพย์สินภายใต้การจัดการ** | *สินทรัพย์ภายใต้การดูแล* |
| | **Subscription / Redemption** | **การสั่งซื้อหน่วยลงทุน / การขายคืนหน่วยลงทุน** | *การสมัครสมาชิก / การแลกรางวัล* |
| **ประกันภัย (คปภ.)** | **Sum Insured / Sum Assured** | **จำนวนเงินเอาประกันภัย** | *เงินประกันรวม* |
| | **Premium** | **เบี้ยประกันภัย** | *พรีเมียม / ค่าบริการพิเศษ* |
| | **Deductible** | **ค่าเสียหายส่วนแรก** | *ส่วนลดหย่อน* |
| | **Surrender Value** | **มูลค่าเวนคืนกรมธรรม์** | *มูลค่ายอมจำนน* |
| **ตลาดทุน (SET/SEC)** | **Circuit Breaker** | **มาตรการหยุดการซื้อขายชั่วคราว** | *ตัวตัดวงจรไฟฟ้า* |
| | **Yield to Maturity (YTM)** | **อัตราผลตอบแทนจนถึงวันครบกำหนดอายุ** | *ผลผลิตจนถึงครบกำหนด* |
| | **Basis Point (bps)** | **เบซิสพอยต์ / ร้อยละ 0.01 (Basis Point: bps - ศัพท์บัญญัติ: จุดพื้นฐาน)** | *จุดฐาน* |
