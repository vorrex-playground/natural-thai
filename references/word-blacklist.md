# บัญชีคำต้องห้ามและคำที่ควรเลี่ยงในภาษาไทย (Thai Word Blacklist & Anti-AI Lexicon)

> **เป้าหมายหลัก:** กำจัดคำฟุ่มเฟือย สำนวนแปลภาษาอังกฤษ (Translationese) และคำบอกสถานะ AI สำเร็จรูป เพื่อให้ภาษาไทยมีความกระชับ ลื่นไหล และตรงตามเจตนารมณ์แท้จริงของมนุษย์

---

## 1. คำแปลสำนวนภาษาอังกฤษตรงตัว (Calqued Idioms & Metaphors)

| [ไม่แนะนำ] สำนวนแปล AI ที่ต้องตัดทิ้ง | [แนะนำ] คำภาษาไทยที่เป็นธรรมชาติ | คำอธิบายทางภาษาศาสตร์ |
|---|---|---|
| ในตอนท้ายของวัน (At the end of the day) | **ท้ายที่สุดแล้ว / สรุปแล้ว / ในภาพรวม** | สำนวนแปลตรงตัวผิดบริบทภาษาไทย |
| สร้างความมั่นใจว่า (Make sure that) | **ตรวจเช็กให้ชัวร์ / ดูให้เรียบร้อยว่า** | ภาษาอังกฤษใช้ make sure ภาษาไทยใช้ "ตรวจดูให้แน่ใจ / ดูให้เรียบร้อยว่า / เช็กให้ชัวร์ว่า" |
| อยู่บนหน้าเดียวกัน (On the same page) | **เข้าใจตรงกัน / เห็นภาพตรงกัน** | สำนวนเปรียบเทียบภาษาอังกฤษ |
| เป็นเรื่องของเวลา (Matter of time) | **อีกไม่นาน / ขึ้นอยู่กับเวลา** | สำนวนแปลตรงตัว |
| ปลดล็อกศักยภาพ (Unlock potential) | **ดึงจุดเด่นออกมา / ใช้งานได้เต็มที่** | คำโฆษณา AI สำเร็จรูป |

---

## 2. คำอาการนามฟุ่มเฟือย (Nominalization Bloat - "การ / ความ")

ภาษาไทยเป็นภาษาเน้นกริยา (Verb-oriented) ให้ตัดคำว่า "การ/ความ" หน้าคำกริยาออกตามหลัก Transposition (Vinay & Darbelnet 1958):

| [ไม่แนะนำ] สำนวนติดคำนามฟุ่มเฟือย | [แนะนำ] คำกริยาไทยแท้ที่เป็นธรรมชาติ |
|---|---|
| มีความจำเป็นที่จะต้องทำการอัปเดต | **ต้องอัปเดต / จำเป็นต้องอัปเดต** |
| ทำการลบข้อมูล | **ลบข้อมูล** |
| ให้ความช่วยเหลือแก่ผู้ใช้งาน | **ช่วยเหลือผู้ใช้ / ดูแลลูกค้า** |
| ส่งผลกระทบต่อประสิทธิภาพการทำงาน | **ทำให้ระบบช้าลง / กระทบประสิทธิภาพระบบ / ทำงานได้ไม่เต็มที่** |

## 3. กริยาช่วยและคำเชื่อมราชการเทียม (Bureaucratic & Copular Bloat)

| [ไม่แนะนำ] คำเชื่อมแข็งทื่อ | [แนะนำ] คำภาษาพูด/กึ่งทางการที่เป็นธรรมชาติ | ข้อควรระวัง |
|---|---|---|
| **ทำการ... / ดำเนินการ...** | ตัดทิ้ง ใช้กริยาหลักทันที | **ยกเว้น:** คำนามเฉพาะ เช่น "วันทำการ", "เวลาทำการ" ให้คงไว้ |
| **มีความประสงค์ที่จะ...** | **อยาก... / ต้องการ... / ขอ...** | |
| **เป็นที่น่าสังเกตว่า...** | **จะเห็นได้ว่า... / สังเกตว่า...** | |
| **กล่าวโดยสรุปคือ...** | **สรุปคือ... / สรุปง่าย ๆ คือ...** | |

---

## 4. กรรมวาจกเทียมในเหตุการณ์เชิงบวก (Adversative Passive Abuse)

| [ไม่แนะนำ] กรรมวาจกเทียมผิดธรรมชาติ | [แนะนำ] โครงสร้างประธาน-กริยา หรือ Topic-Comment |
|---|---|
| ฟังก์ชันใหม่**ถูกปล่อย**ออกมาแล้ว | **ฟังก์ชันใหม่ออกมาแล้วครับ / ทีมงานปล่อยฟังก์ชันใหม่แล้ว** |
| บัญชีของคุณ**ถูกเปิดใช้งานสำเร็จ** | **เปิดใช้งานบัญชีเรียบร้อยแล้วครับ** |
| โค้ดชุดนี้**ถูกเขียนขึ้นโดย...** | **โค้ดชุดนี้ คุณ... (หรือ ทีมงาน) เขียนขึ้นมาครับ** |

## 5. ตารางป้องกันความหมายเบี่ยงเบน (Semantic & Lexical Drift Prevention Matrix)

| คำต้นฉบับ | ห้ามเปลี่ยนเป็น (Drifted) | คำที่เป็นธรรมชาติและตรงความหมาย (Natural & Invariant) | เหตุผลทางภาษาศาสตร์ |
|---|---|---|---|
| **สร้างความได้เปรียบ** | รักษาความได้เปรียบ | **สร้างความได้เปรียบ** | สร้าง (Create/Gain) คนละสถานะกับ รักษา (Maintain) |
| **องค์กรต่าง ๆ** | บริษัท | **องค์กรต่าง ๆ / ทุกองค์กร** | องค์กร ครอบคลุมทั้งรัฐ เอกชน สถาบัน ห้ามบีบแคบเหลือแค่บริษัท |
| **ความต้องการของผู้บริโภคที่เปลี่ยนไป** | ลูกค้าที่เปลี่ยนใจเร็ว | **ความต้องการของผู้บริโภคที่เปลี่ยนไป / โจทย์ของลูกค้าที่หมุนไป** | ห้ามเปลี่ยนเทรนด์ตลาดเชิงระบบ ให้กลายเป็นความโลเลของบุคคล |
| **จำเป็นต้อง / ต้อง** | ควร / ถ้าสะดวกแนะนำให้ | **ต้อง / จำเป็นต้อง...เลยครับ** | ห้ามลดทอน Deontic Modality จากข้อบังคับเป็นคำแนะนำ |
| **ปรับปรุงประสิทธิภาพ** | แก้ไขข้อผิดพลาด | **ปรับปรุงประสิทธิภาพ / เพิ่มความเร็ว** | ของเดิมไม่ได้พัง (Optimize) คนละความหมายกับของเดิมมีบั๊ก (Fix) |
| **วันทำการ** | วันธรรมดา | **วันทำการ** | "วันทำการ" เป็นศัพท์ทางกฎหมายและการเงินที่ถูกต้อง ห้ามตัดทอน |

## 6. ศัพท์ประดิษฐ์และศัพท์กฎหมายลูกผสมที่ผิดธรรมชาติ (Franken-Jargon & Fake Legalisms)

| [ไม่แนะนำ] ศัพท์ประดิษฐ์ AI ที่ไม่มีใครใช้ | [แนะนำ] ภาษาทางการ / ภาษากฎหมายที่ถูกต้อง | [แนะนำ] ภาษาทำงานจริง / ไอที (Natural Working IT) | คำอธิบาย |
|---|---|---|---|
| **ข้อมูลบันทึกจราจรทางคอมพิวเตอร์** | **ข้อมูลจราจรทางคอมพิวเตอร์** | **ประวัติการเข้าใช้งานระบบ (Log) / บันทึก Log** | พ.ร.บ. คอมพิวเตอร์ ม.26 ใช้คำว่า "ข้อมูลจราจรทางคอมพิวเตอร์" ห้ามเติม "บันทึก" ซ้ำซ้อน ส่วนคนทำงานเรียก Log สั้น ๆ |
| **ระบบ Redis Cluster จะระงับบัญชี (เมื่อคุยกับลูกค้า)** | **ระบบจะระงับการใช้งานบัญชีของท่าน...** | **ระบบจะระงับบัญชี...** | ลูกค้าทั่วไปไม่เข้าใจ Backend Architecture ห้ามหลุดชื่อ Service ภายในไปหาลูกค้า |
| **เพื่อให้ [ชื่อองค์กร] สามารถ...** | **เพื่อความสะดวกของผู้ใช้บริการ...** | **[เข้าประเด็นเงื่อนไขทันที]** | สำนวนแปล AI (In order for [Company] to...) ธนาคารไทยไม่พูดเอาตัวเองเป็นศูนย์กลาง |
| **การมีเลือดออกของระบบ** | **ระบบขาดทุนสะสม / ขาดสภาพคล่อง** | **ระบบ Cash Burn สูง / กำลังขาดทุน** | สำนวนแปลตรงตัวจาก bleeding |

## 7. ศัพท์ประดิษฐ์และคำแปลกของ AI ยุคใหม่ (Modern GenAI & LLM Jargon Traps 2025-2026)

| ศัพท์อังกฤษ (AI/LLM Term) | คำแปลกที่ AI ชอบใช้ (ห้ามใช้) | คำที่เป็นธรรมชาติ (Natural Thai / Tier 2) |
|---|---|---|
| **Prompt** | *คำกระตุ้นเตือน, คำสั่งพร้อม, ตัวสะกิด* | **พรอมต์ / คำสั่ง** (หรือคงรูป `Prompt`) |
| **Context Window** | *หน้าต่างบริบท, บานหน้าต่างบริบท* | **Context Window** (หรือ *ความยาวบริบทที่รองรับ*) |
| **Chain of Thought (CoT)** | *ห่วงโซ่แห่งความคิด, โซ่ความคิด* | **Chain of Thought (CoT)** (หรือ *การคิดทีละสเต็ป*) |
| **Hallucination** | *อาการประสาทหลอนของโมเดล* | **การกุข้อมูลขึ้นมาเอง / การให้ข้อมูลคลาดเคลื่อน / โมเดลมั่ว (ภาษาพูด) / Hallucination** |
| **Guardrails** | *ราวกั้นความปลอดภัย, รั้วกั้นนิรภัย* | **Guardrails** (หรือ *กรอบความปลอดภัยของระบบ*) |
| **Fine-tuning** | *การปรับแต่งอย่างละเอียดอ่อน, การปรับแต่งอย่างประณีต* | **Fine-tuning / ไฟน์ทูน** (หรือ *การเทรนเฉพาะทาง*) |
| **Latency** | *เวลาแฝง, ความแฝง* | **Latency / ความหน่วง / เวลาตอบสนอง** |
| **Inference** | *การอนุมานผลลัพธ์* | **Inference / ตอนรันประมวลผลจริง** |
| **Embeddings** | *การฝังตัว, เวกเตอร์ฝังตัว* | **Embeddings / เวกเตอร์แทนความหมาย** |
| **RAG** | *การสร้างแบบเสริมด้วยการดึงข้อมูล* | **RAG / ระบบดึงข้อมูลมาช่วยตอบ** |
| **AI Agent** | *ตัวแทนอัจฉริยะ, นายหน้าอัตโนมัติ* | **AI Agent / ระบบ Agent** |
| **Temperature** | *อุณหภูมิของคำตอบ* | **ค่า Temperature / ค่าความสุ่มความคิดสร้างสรรค์** |
| **Throughput** | *ผลงานผลิตภาพผ่านระบบ* | **Throughput / ความเร็วประมวลผล (token/sec)** |
| **Delve / Deep dive** | *ดำดิ่งสู่ห้วง... / เจาะลึกเข้าไปใน...* | **มาดูรายละเอียดกัน / ศึกษาเชิงลึก** |
| **Seamless** | *อย่างราบรื่นไร้รอยต่อ* | **ใช้งานได้ลื่นไหล / ไม่สะดุด / เชื่อมต่อทันที** |
