# คำที่ควรหลีกเลี่ยงและคำที่สะกดผิดบ่อย

ไฟล์นี้เป็นรายละเอียดเพิ่มเติมของ SKILL.md
เอาไว้เช็กเวลาเขียนแล้วไม่แน่ใจว่าคำไหนควรใช้หรือไม่ควรใช้ รวมถึงคำที่สะกดผิดบ่อยทั้งคำไทยแท้และคำทับศัพท์

---

## 1. คำเชื่อมที่ทำให้ดูเป็น AI

คำพวกนี้ไม่ผิดหรอก แต่ถ้าใช้บ่อยหรือใช้ผิดที่ จะทำให้อ่านแล้วรู้สึกว่าเหมือน AI เขียน หรือเป็นสำนวน AI ที่ดูไม่เป็นธรรมชาติ

- "ยิ่งไปกว่านั้น" ให้ใช้ "แถมยัง" "แล้วก็" หรือ "อีกอย่างคือ" ถ้าไม่จำเป็นต้องเชื่อมก็ขึ้นประโยคใหม่เลย (ห้ามใช้คำโบราณอย่าง "อนึ่ง" "ทั้งนี้" มาแทน)
- "อย่างไรก็ตาม" ให้ใช้ "แต่" หรือ "แต่ว่า" ไม่ต้องเป็นทางการขนาดนั้น (ห้ามใช้คำโบราณอย่าง "ทว่า" มาแทน)
- "นอกจากนี้" ให้ใช้ "แล้วก็" หรือ "อีกอย่าง"
- "ในส่วนของ" + ชื่อหัวข้อ ให้เริ่มด้วยหัวข้อเลย (เช่น "ในส่วนของราคา..." เปลี่ยนเป็น "ราคา...")
- "ดังนั้น" "เพราะฉะนั้น" ให้ใช้ "เลย" "ก็เลย" หรือ "เพราะงั้น"
- "โดยเฉพาะอย่างยิ่ง" ให้ใช้แค่ "โดยเฉพาะ"
- "ในทางกลับกัน" ให้ใช้ "กลับกัน" หรือ "ตรงข้ามเลย"
- "กล่าวอีกนัยหนึ่ง" ให้ใช้ "พูดง่าย ๆ ก็คือ" หรือ "หมายความว่า"
- "ส่งผลให้" ให้ใช้ "เลยทำให้" หรือ "ก็เลย"
- "ท้ายที่สุดแล้ว" ให้ใช้ "สุดท้าย" หรือ "สุดท้ายก็"

## 2. วลีสรุปและสำนวนสำเร็จรูปของ AI (AI Clichés)

- "สรุปได้ว่า" "โดยสรุปแล้ว" "กล่าวโดยสรุป" ไม่ต้องประกาศว่ากำลังสรุป ให้สรุปใจความไปเลย
- "จากที่กล่าวมาข้างต้น" ตัดออกเลย ถ้าสรุปดี คนจะเข้าใจเองว่าเนื้อหามาจากที่พูดก่อนหน้า
- "สิ่งสำคัญคือ" บอกเรื่องสำคัญไปเลย
- "ในยุคดิจิทัลปัจจุบัน..." "ในโลกที่เทคโนโลยี..." ตัดทิ้งเลย ให้เข้าประเด็นทันที
- "ปลดล็อกศักยภาพ..." เปลี่ยนเป็น "ช่วยให้ทำงานได้ดีขึ้น" หรือพูดผลลัพธ์ตรง ๆ
- "สร้างประสบการณ์ที่ไร้รอยต่อ..." เปลี่ยนเป็น "ใช้งานง่าย ไม่สะดุด"
- "ตอบโจทย์ทุกไลฟ์สไตล์..." ตัดออกแล้วบอกประโยชน์ที่ลูกค้าจะได้รับตรง ๆ
- "ยกระดับประสบการณ์ของคุณไปอีกขั้น..." ตัดทิ้ง หรือบอกว่าดียังไง
- "คุณเคยประสบปัญหา...หรือไม่? ถ้าใช่..." ตัดคำถามนำ ให้เริ่มด้วย Pain point จริงทันที
- "ขับเคลื่อน..." (เมื่อใช้พร่ำเพรื่อ) เปลี่ยนเป็น "ช่วยผลักดัน" "พัฒนา" หรือ "ทำให้เดินหน้า"
37: - "ไม่ว่าคุณจะเป็น [A] หรือ [B]..." ตัดออกแล้วบอกประโยชน์ตรง ๆ
38: - "สำหรับผลงานเด่น ๆ ของผม..." "ผลงานอันโดดเด่น..." (ในบริบทบทพูดสัมภาษณ์/เล่าเรื่อง) ให้เปลี่ยนเป็น "ส่วนโปรเจกต์ของผมก็จะมี..." หรือ "ผลงานที่ผ่านมาก็มี..." เพื่อให้ฟังดูเป็นธรรมชาติเข้าปากคนจริง ไม่เหมือนท่องสคริปต์
39: - แปลศัพท์ดีไซน์ฝืนธรรมชาติ : ห้ามแปล Wireframe เป็น "โครงลวด", Key Visual เป็น "ภาพหลักแห่งสายตา", User Journey เป็น "การเดินทางของผู้ใช้", Pain Point เป็น "จุดเจ็บปวด", Drop-off เป็น "การตกหล่น", Bleed เป็น "การมีเลือดออก", Create Outline เป็น "สร้างเส้นขอบนอก", Die-cut เป็น "การตัดให้ตาย" (ให้ทับศัพท์ภาษาอังกฤษตามสากล)
40: - สำนวนเรซูเม่ลอย ๆ ไร้ตัวเลข : ห้ามใช้ "เป็นคนขยันหมั่นเพียร", "มีความกระตือรือร้นสูงมาก", "สามารถทำงานภายใต้แรงกดดันได้ดี", "รักการเรียนรู้และพัฒนาตนเองตลอดเวลา", "Hard-working team player", "Responsible for..." (ให้เปลี่ยนเป็น Action Verbs + ตัวเลขผลงานตามสูตร Google XYZ Formula)

## 3. คำทางการเกินไป

- "ดำเนินการ" ให้ใช้ "ทำ" "จัดการ" หรือ "ลงมือ" (เช่น "ดำเนินการแก้ไข" เปลี่ยนเป็น "แก้")
- "มีบทบาทสำคัญ" ให้ใช้ "สำคัญ" "ช่วยได้มาก" หรือ "เป็นตัวหลัก"
- "ภูมิทัศน์" (ของเทคโนโลยี / อุตสาหกรรม) ให้ใช้ "วงการ" "สถานการณ์" หรือ "แวดวง"
- "สอดคล้องกับ" ให้ใช้ "ตรงกับ" "เข้ากับ" หรือ "ไปในทางเดียวกับ"
- "มีความสำคัญอย่างยิ่ง" ให้ใช้ "สำคัญมาก"
- "ประยุกต์ใช้" ให้ใช้ "เอามาใช้" หรือ "นำมาใช้"
- "ตลอดจน" ให้ใช้ "รวมถึง" หรือ "แล้วก็"
- "อาทิ" ให้ใช้ "เช่น"
- "ถึงแม้ว่า" ให้ใช้ "แม้" หรือ "ถึงจะ"
- "เป็นที่ประจักษ์" ให้ใช้ "เห็นชัดว่า" หรือ "ชัดเจนว่า"
- "มิได้" "หามิได้" "มิใช่" (ในแชททำงานทั่วไป) ให้ใช้ "ไม่ได้" "ไม่ใช่" หรือ "เปล่าครับ"

## 4. คำฟุ่มเฟือยที่ตัดออกได้เลย

- "ทำการ" + กริยา ให้ใช้แค่กริยา (เช่น "ทำการตรวจสอบ" เปลี่ยนเป็น "ตรวจสอบ" หรือ "เช็ก")
- "มีความ" + คุณศัพท์ ให้ใช้แค่คุณศัพท์ (เช่น "มีความสำคัญ" เปลี่ยนเป็น "สำคัญ")
- "มีการ" + กริยา ให้ใช้แค่กริยา (เช่น "มีการเปลี่ยนแปลง" เปลี่ยนเป็น "เปลี่ยนแปลง")
- "เพื่อที่จะ" ให้ใช้แค่ "เพื่อ" (เช่น "เพื่อที่จะบันทึก" เปลี่ยนเป็น "เพื่อบันทึก")
- "สามารถที่จะ" ตัดออกหมด (เช่น "สามารถที่จะทำได้" เปลี่ยนเป็น "ทำได้")
- "มีความสามารถในการ" ตัดออกแล้วใช้กริยาเลย
- "โดยทั่วไปแล้ว" ให้ใช้ "ปกติ" หรือ "ส่วนใหญ่"
- "ในปัจจุบันนี้" "ณ ขณะนี้" ให้ใช้ "ตอนนี้"

## 5. คำไทยแท้ที่มักสะกดผิด (ต้องแก้ให้ถูกต้อง 100%)

- สังเกตุ -> **สังเกต**
- อนุญาติ -> **อนุญาต**
- นะค่ะ -> **นะคะ**
- ลายเซ็นต์ -> **ลายเซ็น**
- รสชาด -> **รสชาติ**
- กระทันหัน -> **กะทันหัน**
- โอกาศ -> **โอกาส**
- กฏหมาย / กฏเกณฑ์ -> **กฎหมาย / กฎเกณฑ์** (ใช้ ฎ ชฎา)
- ปรากฎ -> **ปรากฏ** (ใช้ ฏ ปฏัก)
- สัมนา -> **สัมมนา**
- ผลัดวันประกันพรุ่ง -> **ผัดวันประกันพรุ่ง**
- เบื่องต้น -> **เบื้องต้น**

## 6. คำทับศัพท์ที่สะกดผิดบ่อย (ต้องแก้ให้ถูกตามราชบัณฑิตยสภา)

- เช็ค (ที่หมายถึงตรวจสอบ) -> **เช็ก** (Check)
- อัพเดท / อัปเดท -> **อัปเดต** (Update)
- อัพโหลด -> **อัปโหลด** (Upload)
- เวอร์ชั่น -> **เวอร์ชัน** (Version)
- โปรเจค / โปรเจ็ค -> **โปรเจกต์** (Project)
- เซอร์เวอร์ / เซิฟเวอร์ -> **เซิร์ฟเวอร์** (Server)
- คลิ๊ก -> **คลิก** (Click)
- บล็อค -> **บล็อก** (Blog / Block)
- ดิจิตอล -> **ดิจิทัล** (Digital)
- อีเมล์ -> **อีเมล** (Email)
- อินเตอร์เน็ต -> **อินเทอร์เน็ต** (Internet)
- แอพ / แอพพลิเคชั่น -> **แอป / แอปพลิเคชัน** (App / Application)
- ลิ้งก์ / ลิ้งค์ / ลิงค์ -> **ลิงก์** (Link)
- ฟังก์ชั่น -> **ฟังก์ชัน** (Function)
- สคริปท์ -> **สคริปต์** (Script)
- คอมเม้นท์ -> **คอมเมนต์** (Comment)
- โพสท์ / โพส -> **โพสต์** (Post)
- โค๊ด -> **โค้ด** (Code)
- แพคเกจ / แพ็คเกจ -> **แพ็กเกจ** (Package)
- กราฟฟิก -> **กราฟิก** (Graphic)
- ไลบรารี่ -> **ไลบรารี** (Library)
- อัลกอริทึ่ม -> **อัลกอริทึม** (Algorithm)
- อินเตอร์เฟซ / อินเตอร์เฟส -> **อินเทอร์เฟซ** (Interface)
- คอมโพเน้นท์ / คอมโพเนนท์ -> **คอมโพเนนต์** (Component)
- ไดเรกทอรี่ / ไดเร็คทอรี่ -> **ไดเรกทอรี** (Directory)
- เมธ็อด / เมทอด -> **เมธอด** (Method)

## 7. เช็กตัวเองก่อนส่ง

- มีคำจากรายการนี้ไหม? ถ้ามี ให้เปลี่ยน
- มีคำไทยหรือคำทับศัพท์ที่สะกดผิดไหม? (เช่น สังเกต, อนุญาต, นะคะ, เช็ก, อัปเดต)
- ใช้ลักษณนามถูกต้องไหม? (รายงาน 2 ฉบับ, เซิร์ฟเวอร์ 2 เครื่อง, บั๊ก 3 จุด)
- คำขยายอยู่หลังคำนามไหม? (ไม่แปลคำขยายนำหน้านามแบบอังกฤษ)
- ใช้คำลงท้าย (ครับ/ค่ะ) สม่ำเสมอ ไม่สลับเพศไปมาในข้อความเดียวกันไหม?
- มีการเว้นวรรค 1 เคาะ ระหว่างภาษาไทยกับภาษาอังกฤษและตัวเลขไหม?
- มีการเว้นวรรคหน้าและหลังไม้ยมก (ๆ) ไหม?
- ประโยคยาวเกิน 2 บรรทัด หรือมี "ซึ่ง... ที่มี... ในการ..." ซ้อนยาวไหม? ถ้ามี ให้ตัดแบ่ง
- อ่านแล้วเหมือนหนังสือเรียนหรือเอกสารราชการไหม? ถ้าใช่ ปรับให้เป็นภาษาพูดขึ้น
- มีศัพท์เทคนิคที่ไม่ได้อธิบายไหม? ถ้ามี ใส่คำอธิบายสั้น ๆ
- มี emoji ไอคอน หรือเครื่องหมายขีดยาว (em dash) ไหม? ถ้ามี ตัดออก
- มีคำ cliché แบบ AI ไหม? (เช่น "ปลดล็อกศักยภาพ" "ไร้รอยต่อ" "ในยุคปัจจุบัน") ถ้ามี ให้ตัดหรือเปลี่ยน
- เมื่อตอบยาว ยังคุมโทนภาษาคนได้ดีอยู่ไหม? อย่าเผลอกลับไปใช้สำนวน AI
- คนที่ไม่ได้อยู่ในสายงานนี้อ่านแล้วเข้าใจไหม? ถ้าไม่ ปรับ
